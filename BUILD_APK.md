# Как получить тестовый APK

В проекте настроена автоматическая сборка debug APK через GitHub Actions. Она использует JDK 17, Android SDK 35 и Gradle 8.9.

## Вариант 1 — GitHub Actions

1. Создайте пустой репозиторий на GitHub.
2. Распакуйте архив проекта и загрузите **содержимое** папки проекта в корень репозитория (папка `.github` должна сохраниться).
3. Откройте вкладку **Actions** и разрешите запуск workflows, если GitHub попросит.
4. Выберите **Build Android APK** → **Run workflow**.
5. Дождитесь зелёного статуса. Внизу страницы запуска скачайте артефакт `RussianFishingReborn-0.29.0-debug`.
6. Распакуйте артефакт ZIP. Внутри будет `app-debug.apk`; перенесите его на Android и установите.

При первой установке Android может попросить разрешить установку приложений из выбранного источника. Это тестовая debug-сборка, не релиз для Google Play.

## Вариант 2 — Android Studio

1. Установите Android Studio с Android SDK Platform 35.
2. Откройте корень проекта как существующий Gradle-проект.
3. Установите JDK 17 и Gradle 8.9 (Android Studio обычно импортирует Gradle автоматически, если настроен wrapper; в этом архиве wrapper пока не включён).
4. Запустите задачу `:app:assembleDebug`.
5. APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

## Важное

- `debug` APK предназначен для тестирования, он не подписан релизным ключом.
- Для онлайн-функций нужен доступный HTTPS-адрес игрового сервера; без него одиночная игра должна запускаться, но сетевые возможности будут недоступны.
- До публикации нужно выполнить полноценную Android-сборку, проверить запуск и основные сценарии на реальном устройстве, а затем настроить release-подпись.
