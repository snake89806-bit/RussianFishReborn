# Русская Рыбалка: Reborn — 0.29.0

Android-игра с одиночной рыбалкой и подключаемой сетевой основой. В проекте есть 15 видов рыб, трофеи, снасти, прикормка, сезонность, задания, достижения, локальные турниры, серверный API, экран аккаунта и общий онлайн-рейтинг.

## Онлайн-подключение

1. Разверните сервер из каталога `server/` за HTTPS reverse proxy. Инструкция и API-контракт находятся в [`server/README.md`](server/README.md).
2. Запустите Android-приложение, нажмите **ОНЛАЙН** в верхней панели.
3. Нажмите **ВОЙТИ / РЕГИСТРАЦИЯ**. При первом подключении укажите HTTPS-адрес сервера, затем войдите или создайте аккаунт.
4. Нажмите **ОБНОВИТЬ ОБЩИЙ РЕЙТИНГ**. Уловы будут отправляться автоматически; если связи нет, они останутся в локальной очереди до следующей попытки.

Быстрый запуск сервера:

```sh
cd server
export JWT_SECRET="$(openssl rand -hex 32)"
export ADMIN_USERNAME="owner"
export ADMIN_PASSWORD="сильный-уникальный-пароль"
go test ./...
go run ./cmd/server
```

Для публичного подключения настройте домен и HTTPS. Не публикуйте прямой HTTP-порт.

## События и новости

Экран онлайн-клуба загружает публичные настройки и объявления с сервера. Кнопка «Новости и события клуба» показывает активный ивент, активный турнир и последние объявления. Экран локального турнира отдельно показывает, запущен ли онлайн-турнир администратором. При активном турнире авторизованный игрок может вступить с сервера; сервер хранит список участников и строит отдельный рейтинг по уловам, отправленным после вступления. Повторная заявка идемпотентна. Рейтинг сортируется по самой тяжёлой рыбе, затем по суммарному весу.

## Важные ограничения

Сервер пока альфа-версия с JSON-хранилищем для одного процесса. Проверка улова пока не является авторитетной симуляцией игры, поэтому модифицированный клиент может подделать результат. Онлайн-рейтинг турнира уже агрегируется сервером, но исходные уловы всё ещё поступают от клиента и не защищены полноценным античитом. Не используйте его для ценных призов до внедрения авторитетной серверной симуляции. Онлайн-админ-панель и информационное отображение событий подключены в исходниках, но требуют Android-сборки и проверки на устройстве.

## Android-сборка

Откройте проект в Android Studio. Требуется Android SDK 35 и Android Gradle Plugin 8.7.3. Минимальная версия Android — API 23. APK в этой среде не собирался и не проверялся на устройстве.

## 0.29.0 — новогодний сезон
- Праздничная зимняя тема и иллюстрация события.

- Добавлена иконка Android-приложения в нескольких плотностях.
- Важно: прогресс и монетные награды новогодних заданий пока локальные на устройстве, не синхронизируются с сервером и не защищены от модификации клиента.
